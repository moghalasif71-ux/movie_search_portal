# Movie Search

A single-page web app to search movies and save favourites, built with HTML, CSS and JavaScript using the OMDb REST API.

**Live demo:** https://moghalasif71-ux.github.io/movie_search_portal/

## Features
- Search movies by title and browse results in a poster grid
- Details modal with plot, cast, runtime, genre and IMDb rating
- Favourites saved in browser localStorage, so they persist across sessions
- Error handling for no results, invalid API key and network failures

## Tech Stack
HTML5, CSS3, JavaScript (ES6), Fetch API, OMDb API

## Run locally
1. Clone the repo or download the files.
2. Get a free API key from https://www.omdbapi.com/apikey.aspx
3. Open `script.js` and replace `YOUR_OMDB_KEY` with your key.
4. Open `index.html` in your browser.
